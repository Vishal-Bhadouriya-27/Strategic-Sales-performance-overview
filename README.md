# Strategic-Sales-performance-overview
An interactive Power BI dashboard analyzing sales revenue, profitability, profit margins, sub-category performance, and geographic distribution across regions and customer segments. 

## 💡 Executive Summary
* **Total Sales:** $74.26K
* **Total Profit:** $4.62K
* **Overall Profit Margin:** 6.22%

---

## 🔑 Key Features & Insights

* **Category & Sub-Category Performance:** Evaluates revenue generation against total profit per product category (e.g., Chairs, Phones, Paper, Machines, Tables) to highlight high-margin drivers and loss-making items.
* **Temporal Trend Analysis:** Tracks monthly and yearly fluctuations in **Total Sales** alongside **Total Profit Margin %** to identify seasonal peaks and low-performing months.
* **Geographic Distribution:** Visualizes revenue concentration by city across global markets using an integrated Map visual.
* **Interactive Slicers:** Allows dynamic filtering by **Region** (Central, East, South, West) and **Customer Segment** (Consumer, Corporate, Home Office).

---

## 🛠️ Tools & Technologies Used
* **Business Intelligence:** Power BI Desktop
* **Data Visualizations:** Scatter Plots, Combo Charts (Line & Bar), Map Visuals, KPI Cards, and Slicers
* **Data Modeling:** DAX (Data Analysis Expressions) for calculated measures (`Total Sale`, `Total Profit`, `Total Margin %`)

---

## 🚀 How to View the Project
1. Download the `.pbix` file included in this repository.
2. Open the file using [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Interact with the region and segment slicers to explore custom views of the data.
